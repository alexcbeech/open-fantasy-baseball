# Security Policy

## Reporting a vulnerability

Please do not report suspected vulnerabilities in a public issue.

Use this repository's **Security** tab to submit a private vulnerability report:

https://github.com/alexcbeech/open-fantasy-baseball/security/advisories/new

Include the affected route or component, reproduction steps, expected impact,
and any suggested mitigation. Do not include real credentials, access tokens,
personal data, or destructive proof-of-concept payloads.

You should receive an acknowledgement within seven days. Confirmed issues will
be prioritized based on exploitability and impact, with coordinated disclosure
after a fix is available.

## Supported version

Security fixes are applied to the current production version on `main`.
